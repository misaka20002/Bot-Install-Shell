# 云崽开发环境清理

入口：`系统管理 → 4. 清理系统垃圾 → 2. 云崽开发环境清理`。

确认后清理 pnpm 无引用包、npm 缓存、当前用户的 npm `_npx` 与 pip/pnpm/node-gyp 缓存、APT 缓存与索引，并轮转 journal 后保留约 50M。工具未安装时跳过；旧版 APT 若不支持 `distclean`，索引清理会明确报错，不绕过 APT 锁直接删除。缓存重建需要重新下载。

Hapi 按 `HAPI_HOME`（默认 `~/.hapi`）定位运行时。参考 Hapi 源码 `cli/src/projectPath.ts`、`configuration.ts`、`runtime/assets.ts`：编译版按包版本选择 runtime 子目录，并写入 `.runtime-version`。只将早于当前命令版本、标记吻合的普通目录列为候选，展示大小并单独确认。当前版本、新版本、软链接和未知目录保留。检测到 Hapi 进程，或版本与进程信息无法可靠读取时，跳过整个 Hapi 清理。建议在停止 Hapi 后执行；确认后会再次检查，但不能防止其他进程恰在删除瞬间启动。

临时目录只匹配 `/tmp` 第一层的 `html-tool-chromium`、`hapi-src`、`clash-review.*`、`sf-douyin-test-venv`、`at-graph-*`，且目录修改时间超过 7 天。展示大小后确认删除。目录修改时间不代表内部文件最近使用时间，确认前应自行确认相关任务已结束。

Docker 展示镜像列表，只删除输入的单个镜像，不加 force；容器引用的镜像交给 Docker 拒绝删除。回车跳过。

最终显示根分区可用空间变化，可能受到同期其他进程读写影响。部分失败返回非零；跳过项单独提示。这里的操作会在运行脚本的 Linux 主机上执行，开发验证不会清理本机数据。

定向验证：`node tests/SYS_Manage/cleanup.test.cjs` 和 `bash tests/SYS_Manage/cleanup-run.sh`。前者以替身检查 Hapi 候选与保留规则，后者检查失败返回及取消路径，不执行真实清理。
